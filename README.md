Retail Sales Analysis Dashboard

Project Overview

This project analyzes retail sales data using Microsoft Excel, MySQL, and Power BI to understand sales performance, profitability, product categories, and regional trends.

Tools Used

- Excel: Data cleaning and preparation
- MySQL: SQL queries and data analysis
- Power BI: Interactive dashboard and visualizations

Dataset

The dataset contains 9,977 retail records with information about shipping mode, customer segment, city, state, region, product category, sub-category, sales, quantity, discount, and profit.

Key Performance Indicators

- Total Sales: 2,296,195.59
- Total Profit: 286,241.42
- Total Quantity Sold: 37,820
- Total Records: 9,977

Analysis Performed

- Overall sales and profit analysis
- Sales and profit by product category
- Regional sales performance
- Customer segment analysis
- Shipping mode analysis
- Discount and profitability analysis
- Sub-category performance analysis

Dashboard

The Power BI dashboard includes KPI cards and charts for sales by category, profit by region, and sales by region.

Business Insights

- Technology generated the highest sales among the three product categories.
- Office Supplies had the highest quantity sold.
- Profitability varied across product categories, highlighting opportunities for further business analysis.

Project Files

- "Retail_Sales_Analysis.xlsx" — Excel dataset
- "Retail_Sales_Analysis.pbix" — Power BI dashboard
- "retail_sales_analysis.sql" — SQL queries

Objective

To demonstrate practical skills in data cleaning, SQL analysis, business insights, and Power BI dashboard development for a Data Analyst role.
